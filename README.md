# Devil Pact

**Devil Pact** is an online co-op survival shooter developed for a game jam in **2 weeks** with a team of **4 people**, using **S&Box** and **C#**.

Created around the theme **“One More Round,”** the game challenges players to survive endless waves of demonic enemies in a dark sci-fi facility. Death is not the end: make a pact with Death to return stronger with a permanent bonus and keep fighting.

S&Box is a platform for creating, sharing, and playing games, powered by an engine built on **Valve’s Source 2**.
